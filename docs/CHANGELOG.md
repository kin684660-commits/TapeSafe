# Changelog

## 0.5.0 · 2026-10-03

- 发布 28 秒 1080p 中文演示、字幕、真实界面截图记录与可编辑 Remotion 工程。
- 提供 GitHub Pages 视频播放器。
- 统一产品标题与部署、验证文档。
- 视频采用中文神经网络合成旁白与原创程序合成配乐。

## 0.5.0 · 2026-10-02

- 更新产品首页与视觉资源。
- 配置 X Layer 主网 CPU #267、Circuit #1、三笔部署交易与发行参数。
- 新增无需钱包的双 RPC 固定区块核验。
- 核验脚本增加创建事件配对、发送者、创建与铸造输入、流片字节和 Circuit ID 检查。
- 14 项 Node 测试通过；未修改合约或 NAND 网表。

## 0.4.0

- 钱包部署助手支持逐笔模拟、签名、收据检查与部署记录导出。
- 支持单价 0.000066 OKB 的费用计算和分叉回归。
- 增加部署助手模拟钱包测试。

## 0.3.0

- 增加实时费用查询、未签名交易生成与模拟。
- 将处理器 / 电路核验和金库扩展核验分开。
- 增加创建、铸造、流片编码回归与零单价分叉测试。

## 0.2.0

- 增加真实网表实验室与 NAND 输出可视化。
- 执行器拒绝死锁配置，冻结使旧提案失效，禁止提前准备解冻。
- 加强权限、CALL-only、有效期、配置、费用与 calldata 检查。
- 前端支持解冻、签名人轮换与上传授权。
- 固定区块双 RPC 比较，交易前代码检查与模拟。
- 增加 ABI 边界验证与完整电路穷举。

执行器语义变化需要部署新合约；替换前端不会更新既有合约行为。
