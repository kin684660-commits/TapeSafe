# 0.2.0 升级记录

- 提交路径改为 GitHub + 部署后视频 + 处理器/电路证据，DeWEB 改为可选；真实地址保留待填。
- 新增运行真实 518 字节网表的电路实验室、74 个 NAND 输出可视化、五种可操作情景和评委核验页。
- 合约拒绝全员门槛/全员必签的死锁配置；冻结使旧提案失效；禁止提前准备解冻；配置目标、金额与解冻 calldata 校验收紧。
- 前端补齐解冻、签名人轮换和上传授权提案；修复非转账提案误带执行费；增加金额精度、地址、calldata 和有效期校验。
- 提案预览保存原期限，提交前重读 previewHash；修改表单会使预览失效。详情显示 calldata、期限、状态；失效提案关闭操作。
- 双 RPC 固定高度并比较区块哈希；交易前校验代码、模块绑定并模拟；增加超时和钱包账户变化处理。
- ABI 拒绝坏 hex、无效地址、溢出和截断数据；新增 address[] 编码与编译选择器验证。
- 修复 maj3 测试失败被后续计数覆盖的问题；四份电路字节交叉验证并穷举浏览器解释器。
- 新增只读部署核验、发布哈希清单、CI、部署交接、安全边界和录制脚本。

合约语义已变化，0.2.0 应部署新的 TapeSafeModule；不能仅替换旧前端就假定旧合约获得这些修复。底层协议的可升级信任风险仍然存在。
