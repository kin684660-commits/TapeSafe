## 复现

```sh
npm test
npm run test:hardware
cd tapesafe_contracts
forge test
forge test --match-contract TapeSafeFork --fork-url https://xlayerrpc.okx.com -vv
```

历史环境：Node.js v24.18.0、Foundry v1.7.1、Solidity 0.8.26，optimizer 200，via_ir。

## 验证边界

执行器与金库未部署，没有真实金库放款证据。现有网表与 BLIF 的一致性已经测试；Verilog 到 BLIF 的独立复现需要重新运行综合工具。测试不等同于安全审计，底层协议可升级。
