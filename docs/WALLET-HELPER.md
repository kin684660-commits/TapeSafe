## 你需要做

1. 连接钱包，确认在 X Layer 196。连接不会发送交易。
2. 点击“① 准备创建处理器”，看页面费用，再点“打开钱包确认这笔交易”，由你在钱包中核对并签名。
3. 成功后点击“② 准备铸造 74 NAND”，核对金额，再由你签名。
4. 成功后点击“③ 准备流片”，核对金额，再由你签名。
5. 三步完成后，点击“下载部署记录”，把下载的 JSON 发给协作者。

每笔准备只做读取与模拟。只有明确点击签名按钮才调用钱包发送交易。不要在上一笔未确认时重复发送；待确认状态会禁用准备按钮，刷新后可连接同一钱包并点击“继续检查已发送交易”。

## 自动核对和限制

助手会检查网络、账户、合约代码、配置单价、模拟结果和预计gas。创建交易需核对工厂登记及两个预测合约的收据事件；若期间其他人创建处理器导致预测失配，会停止并保留交易记录，不应重建。将记录交由协作者解析实际收据。

流片会核对交易输入、收据、铸造事件、19/1/0/74规格和两个eval向量。协作者仍须执行完整的独立证据核验；不能仅凭浏览器本地保存的记录认定部署完成。

本地记录保存在这个浏览器的 localStorage。不要清除浏览器数据或用不同浏览器继续同一次部署。下载记录不包含私钥或助记词，但包含公开地址和交易信息。

如果提示未检测到钱包，检查扩展是否安装/启用且允许访问本地网址。助手的浏览器目视与真实钱包签名尚待你实际操作；当前已通过模拟钱包自动化测试，未广播主网交易。
