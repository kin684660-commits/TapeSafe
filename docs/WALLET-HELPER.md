# 钱包部署助手

在本地预览服务运行时，用安装了 EVM 钱包扩展的浏览器打开 `http://127.0.0.1:8765/deploy.html`。

助手依次处理创建处理器、铸造 74 个 NAND 单元和流片审批电路。每一步先读取费用、编码未签名交易并模拟，再由钱包签名发送。连接钱包或准备交易本身不发送交易。

## 流程

1. 连接钱包并选择 X Layer，Chain ID 196。
2. 准备创建处理器，核对当前协议费用并签名。
3. 等待成功收据，准备铸造 NAND 单元，核对金额并签名。
4. 等待成功收据，准备流片，核对网表参数并签名。
5. 下载部署记录，再运行独立核验脚本。

供应上限和铸造单价从部署配置读取。当前公开实例为 210,000 与 0.000066 OKB，独立部署应核对自己的配置。Gas、协议费用和晶体管铸造金额分别计算，不提供固定美元预算。

## 检查与恢复

助手检查网络、账户、合约代码、费用、模拟结果和预计 Gas。交易待确认时禁用重复发送；刷新后，可连接同一钱包并检查已发送交易。

创建成功后核对工厂登记与收据中的合约配对。若实际创建顺序与模拟预测不同，助手会停止并保留记录，避免重复创建。

流片检查交易输入、铸造事件、电路规格和代表 eval 向量。完整独立验证使用：

```sh
node scripts/verify-chain.mjs --tapeout-tx 0xYOUR_TAPEOUT_TRANSACTION
```

## 数据与测试

进度保存在当前浏览器的 localStorage，部署途中应保留同一浏览器的数据。导出记录包含公开地址和交易信息，不包含私钥或助记词。

部署助手已有模拟钱包自动化测试，当前实例的三笔真实主网交易已保留在 [部署清单](SUBMISSION.md)。钱包扩展需要允许访问本地网址。
